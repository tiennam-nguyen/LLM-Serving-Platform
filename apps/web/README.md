# Web Application (Future Milestone)

This directory is reserved for the future **Web Walking Skeleton** application.

---

## Design Intent & Guidelines

1. **Walking Skeleton Milestone**:
   The web application will be introduced in a future milestone as a lightweight interface to demonstrate end-to-end interactivity (chat streaming and real-time worker status inspection).

2. **Functional & Minimal**:
   The UI should remain functional and minimal rather than turning into a complex design-system project. The primary focus of the platform is reliable multi-worker serving, observability, and benchmark reproducibility.

3. **Zero Early Dependencies**:
   Node.js dependencies and frontend framework scaffolding (e.g., Next.js / Vite / React) are intentionally deferred until the backend serving and gateway contracts are established.
