# Experiment Figures

This directory stores generated charts, plots, and graphical assets used in progress reports, presentations, and the final project documentation.

---

## Guidelines

- All figures must be automatically generated by Python scripts from processed data in `experiments/processed/`.
- File naming should reflect the experiment ID and metric (e.g., `exp01_ttft_cdf.png`, `exp02_throughput_vs_concurrency.pdf`).
- Save vector graphics (`.pdf` / `.svg`) alongside high-resolution raster images (`.png`).
