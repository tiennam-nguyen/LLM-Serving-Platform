# Architecture Decision Records (ADRs)

This directory contains Architecture Decision Records (ADRs) capturing significant technical and architectural choices made throughout the project.

---

## What is an ADR?

An Architecture Decision Record captures an important architectural decision, along with its context, considered alternatives, and consequences.

## Adding a New ADR

1. Copy `docs/adr/template.md` to `docs/adr/ADR-XXX-<short-title>.md`.
2. Fill out all sections, including concrete context, decision rationale, and evidence.
