# Benchmark Traces

This directory contains trace datasets used to replay realistic conversational or multi-turn workloads through the serving platform.

---

## Intended Datasets

- Standard public traces (e.g., ShareGPT conversational traces, LMSYS Chatbot Arena datasets).
- Multi-turn synthetic dialogue traces.
- Prompt prefixes for cache-locality testing (in exploratory phases).

*Note: Large trace datasets should be tracked via download scripts or external storage links rather than bloating the Git repository.*
